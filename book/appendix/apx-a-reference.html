A.1 이 부록이 필요한 사람

이 부록은 통독용이 아니라 참조용입니다. 책을 이미 한 번 읽고 두 번째로 실습하면서 "그 링크가 뭐였더라" 하고 다시 찾는 사람, 혹은 특정 단계에서 막혀 앞 장으로 돌아가지 않고 바로 확인하고 싶은 사람을 위한 페이지입니다.

A.3 배포 전 마지막 체크리스트

실제로 배포하기 전에 아래 항목을 한 번씩 확인하는 것을 권장합니다.

  • API 키가 코드에 하드코딩되지 않고 환경변수에 있는가
  • .env나 Secrets 파일이 Github에 노출되지 않았는가
  • sitemap.xml이 최신인가
  • favicon과 OG 이미지가 기본값이 아닌가
  • ads.txt가 배포됐는가
  • 자동 광고가 활성화됐는가
  • Lighthouse 점수를 확인했는가
  • 콘텐츠가 데이터만 있지 않고 설명 글이 있는가
