부록 H · 용어 사전

본문에 등장한 용어를 가나다순으로 모았습니다. 뜻이 갑자기 안 떠오를 때 색인에서 눌러 바로 정의로 이동해 보세요.

H.1 가나다순 용어 목록

가비아 네임서버 도메인 리포지토리(Repository) 서버리스(Serverless) 애드센스(AdSense) 파비콘(favicon) 환경변수 ads.txt Claude Code CPC(클릭당 비용) Edge Function JSON-LD Lighthouse npm OPEN API Open Graph(OG) Organic Search(자연 검색) robots.txt SEO(검색엔진 최적화) sitemap.xml

가비아

국내 도메인 등록 대행업체 중 하나로, 이 책에서는 날씨 옷차림 추천 사이트의 도메인을 구매하는 데 사용합니다. 구매한 도메인의 네임서버를 Cloudflare로 바꿔서 실제 서비스에 연결합니다.

네임서버

도메인 이름을 실제 서버 주소로 연결해 주는 서버입니다. 가비아에서 산 도메인의 네임서버를 Cloudflare가 안내한 주소로 바꾸면, 이후 도메인 관련 설정을 Cloudflare에서 관리할 수 있습니다.

도메인

사람이 기억하기 쉬운 문자로 된 사이트 주소입니다. 가비아 같은 업체에서 구매한 뒤 네임서버를 연결해야 실제로 사이트에 접속할 수 있습니다.

리포지토리(Repository)

Github에 올라간 프로젝트 코드 저장소입니다. Claude Code로 작업한 코드를 커밋하고 푸시하면 이 리포지토리에 기록되고, 배포 서비스가 이 리포지토리를 보고 자동으로 빌드·배포합니다.

서버리스(Serverless)

직접 서버를 띄우고 관리하지 않아도, 필요할 때만 코드가 실행되는 아키텍처 방식입니다. 이 책의 예제 사이트는 Supabase Edge Function으로 날씨 API를 호출하는 서버리스 구조를 씁니다.

애드센스(AdSense)

사이트에 광고를 게재하고 수익을 나눠 받는 구글의 광고 서비스입니다. 코드를 심고 심사를 통과해야 광고가 게재되며, 이 책 10~11장에서 연동과 승인 과정을 다룹니다.

파비콘(favicon)

브라우저 탭이나 즐겨찾기에 표시되는 작은 사이트 아이콘입니다. favicon.io 같은 도구로 만들어 favicon.ico 파일을 교체하면 사이트 전체에 반영됩니다.

환경변수

API 키처럼 코드에 직접 적으면 안 되는 값을 코드 밖에 따로 저장해 두는 설정값입니다. WeatherAPI 키 같은 민감한 값은 환경변수로 관리해야 Github에 그대로 노출되는 것을 막을 수 있습니다.

ads.txt

이 사이트가 어떤 광고 판매자와 실제로 계약된 게시자인지 알려주는 텍스트 파일입니다. 애드센스 심사에 승인된 뒤에도 이 파일을 배포해야 광고가 정상적으로 게재됩니다.

Claude Code

Anthropic이 만든 터미널 기반 AI 코딩 도구로, 이 책의 모든 실습에서 기준으로 쓰는 AI 코딩 도구입니다. 프로젝트 폴더에서 claude를 실행해 자연어로 말을 걸면 파일을 읽고 쓰고, 명령어 실행과 git commit·push까지 대신 처리해 줍니다. Cursor처럼 파일 목록과 대화창을 함께 보여주는 편집기형 도구를 선호한다면 참고로 대신 써도 됩니다.

CPC(클릭당 비용)

사용자가 광고를 한 번 클릭할 때마다 광고주가 지불하는 금액입니다. 애드센스 수익은 CPC와 클릭 수에 따라 달라지며, 저자의 qwzd.kr도 이 방식으로 2년간 약 910달러를 벌었습니다.

Edge Function

사용자와 가까운 위치의 서버에서 짧게 실행되는 함수입니다. 이 책에서는 Supabase Edge Function으로 WeatherAPI를 호출하고 결과를 사이트에 전달합니다.

JSON-LD

웹페이지 정보를 검색엔진이 이해할 수 있는 구조화된 형태로 표시하는 방식입니다. <script type="application/ld+json"> 태그 안에 넣어야 검색엔진이 사이트 성격을 정확히 파악합니다.

Lighthouse

구글이 만든 웹사이트 품질 측정 도구로, 성능·접근성·SEO 등을 점수로 보여줍니다. 사이트 품질은 애드센스 승인에도 영향을 줄 수 있어 배포 전 점검하는 것이 좋습니다.

npm

Node.js 프로젝트의 패키지를 설치·관리하는 도구입니다. npm run dev처럼 명령어로 로컬 개발 서버를 띄우거나 필요한 라이브러리를 설치할 때 씁니다.

OPEN API

누구나 사용할 수 있도록 공개된 외부 API입니다. 이 책에서는 WeatherAPI가 대표적인 OPEN API로, 날씨 데이터를 가져오는 데 사용합니다.

Open Graph(OG)

링크가 카카오톡·페이스북 등에 공유될 때 어떤 이미지·제목·설명으로 보일지 정하는 메타 태그 규칙입니다. og-image는 1200×630 규격을 지켜야 플랫폼마다 이미지가 깨지지 않습니다.

Organic Search(자연 검색)

광고가 아니라 검색 결과에서 자연스럽게 클릭되어 들어오는 유입입니다. 서치콘솔에서 어떤 키워드로 Organic Search 유입이 일어나는지 확인할 수 있습니다.

robots.txt

검색엔진 크롤러에게 사이트의 어떤 페이지를 수집해도 되는지 알려주는 파일입니다. sitemap.xml과 함께 두면 검색엔진이 사이트 구조를 더 잘 파악합니다.

SEO(검색엔진 최적화)

검색 결과에 사이트가 더 잘 노출되도록 다듬는 작업 전체를 말합니다. sitemap.xml 제출, JSON-LD 추가, 콘텐츠 보강 등이 모두 SEO 작업에 해당합니다.

sitemap.xml

사이트 안의 페이지 목록을 검색엔진에게 지도처럼 건네주는 파일입니다. 구글 서치콘솔 같은 곳에 이 파일을 제출하면 검색엔진이 페이지를 더 빠르고 정확하게 수집합니다.
