# 목차 (Single Source of Truth)

> 이 파일이 책 목차의 **유일한 원본**입니다.
> `tools/build_toc.py` 가 이 파일을 읽어 모든 쪽의 사이드바와
> 이전/다음 이동을 만듭니다.
> **각 쪽의 HTML 목차를 손으로 고치지 마십시오.**

## 파싱 규칙

- `## PART n · 제목` → 부(部)
- `### [id] 제목 | 쪽수 | 상태` → 쪽
- `- n.n 제목` → 절 (쪽 안의 `<section id="s1-1">` 에 대응)
- 상태: `todo` / `wip` / `done`

### id 가 폴더를 정합니다

| id 모양 | 들어가는 곳 |
|---|---|
| `prologue` `howto` | `front/` |
| `ch01` `ch02` … | `chapters/` |
| `apx-a-…` `apx-b-…` | `appendix/` |
| 그 밖 (`epilogue` `colophon` `changelog`) | `back/` |
