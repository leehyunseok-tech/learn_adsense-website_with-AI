PART 5 · 브랜딩과 수익화

10

구글 애드센스 연동하고 심사받기

사이트가 완성됐다면 이제 진짜 수익화 단계입니다. 애드센스 코드를 심고, 심사를 요청하고, 승인이 난 뒤에도 해야 할 일이 남아 있다는 것까지 순서대로 따라갑니다.

약 20분 예제 2개 연습문제 3문항

이 장을 끝내면 할 수 있는 것

  • 애드센스 코드를 사이트에 삽입하고 사이트 연결을 완료할 수 있습니다.
  • 심사를 요청하고, 승인 후 ads.txt까지 배포해 광고 게재를 완성할 수 있습니다.
  • 자동 광고와 자동 최적화를 켜서 별도 조정 없이 수익을 최적화할 수 있습니다.

10.1 애드센스 코드 심고 사이트 연결하기

정보 입력을 마쳤다면 애드센스에 사이트를 연결할 차례입니다. 애드센스 화면에서 "사용 시작" 버튼을 누르면 사이트에 붙여 넣을 코드 스니펫을 받습니다. 이 코드를 그대로 Claude Code에게 넘겨 사이트의 head에 삽입해 달라고 요청합니다.

[개념] 애드센스 코드 스니펫

구글 애드센스가 발급하는 짧은 자바스크립트 조각으로, 사이트의 head에 심으면 구글이 "이 사이트가 애드센스와 연결됐다"는 것을 확인할 수 있게 해 줍니다.

[비유] 💡 이렇게 생각해 보세요

애드센스 심사는 매장이 쇼핑몰에 입점하기 전 받는 심사예요. 코드를 심는 건 "저 여기 입점 신청했어요"라고 알리는 팻말을 거는 것이고, 쇼핑몰(구글)이 매장을 둘러보고 나서 광고를 걸어도 될지 최종 판단해요.

배포가 끝나서 코드가 실제로 반영된 것을 확인했다면, 애드센스 화면으로 돌아가 "코드를 삽입했습니다" 체크박스에 체크하고 확인 버튼을 누릅니다. 저자는 애드센스 코드 스니펫뿐 아니라 메타 태그로도 한 번 더 사이트 연결을 확인해 두었습니다.

[주의] 심사 요청 후 사이트를 계속 뒤집어엎는 함정

심사를 요청한 뒤 초조한 마음에 사이트 구조를 계속 크게 바꾸면, 구글이 다시 보는 사이트가 계속 달라져서 재심사처럼 시간이 늦어지거나 혼란을 줄 수 있습니다. 심사 대기 중에는 콘텐츠를 보강하는 정도로 작은 개선에 집중하는 편이 낫습니다.

10.2 심사 요청부터 ads.txt까지

사이트 연결까지 끝나면 "검토 요청" 버튼을 눌러 심사를 요청합니다. 이때부터 애드센스 심사가 시작됩니다. 저자의 경험상 심사 기간은 최소 2~3일에서 길게는 2주까지 걸리며, 결과는 이메일로 통보됩니다.

[비유] 🔧 이렇게 생각해 보세요

ads.txt는 이 매장이 진짜 내 것이라는 사업자등록증 같은 거예요. 심사를 통과했어도 이 등록증을 걸어 두지 않으면, 다른 사람이 이 매장 이름을 빌려서 광고를 붙이는 걸 구글이 걸러내지 못해요. 그래서 승인 후에도 ads.txt를 꼭 배포해야 해요.

심사가 승인되면 애드센스가 ads.txt 파일을 추가하라고 안내합니다. 이것도 그동안 해온 것처럼 Claude Code에게 맡깁니다. ads.txt를 추가하고 배포까지 끝내야 비로소 광고 게재 준비가 최종적으로 완료됩니다.

[AI에게] AI에게 이렇게 시켜보세요

애드센스에서 받은 코드를 사이트에 심어줘. [내 환경] Next.js 프로젝트이고, 페이지가 여러 개(홈, 상세, 소개 등) 있어. 받은 코드는 아래야. <script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-XXXXXXXXXX"></script> [하고 싶은 것] - 이 코드를 모든 페이지의 head에 공통으로 들어가게 넣어줘 [꼭 지켜줘] - 홈페이지에만 넣지 말고, 레이아웃 공통 파일에 넣어서 모든 페이지에 적용해줘 마지막에 위험한 곳을 짚어줘.

이런 답이 오면 정상 — layout 파일처럼 모든 페이지가 공유하는 공통 파일 하나에 스크립트를 넣었다고 안내하고, 개별 페이지 파일에는 손대지 않았다고 짚어 줍니다.

[AI 함정] AI가 여기서 틀립니다

"사이트에 코드를 넣어줘"라고만 요청하면 AI는 지금 보고 있는 홈페이지 파일에만 코드를 넣는 경우가 많습니다. 홈페이지에서는 광고가 잘 뜨기 때문에 문제를 눈치채기 어렵지만, 다른 페이지로 넘어가면 광고가 아예 뜨지 않습니다.

[X] AI가 준 코드 
// app/page.tsx (홈페이지)에만 스크립트 추가
문제 
· 홈페이지에서는 광고가 정상 표시됨
· 상세 페이지·소개 페이지에서는 광고가 아예 안 뜸
[O] 고친 코드 
// app/layout.tsx (공통 레이아웃)에 스크립트 추가

이걸 잡아낸 개념 — 10.1절에서 다룬 "사이트 전체 연결"이라는 개념이, 페이지 하나가 아니라 모든 페이지에 코드가 있어야 한다는 것을 잡아냅니다.

10.3 자동 광고로 수익 최적화하기

ads.txt까지 배포했다면 이제 자동 광고를 설정할 차례입니다. 애드센스 광고 단위 화면에서 수정 버튼을 누르고, 자동 광고를 활성화합니다. 자동 최적화도 함께 활성화하는 것을 권장합니다.

자동 최적화는 구글이 여러 광고 배치를 실험해 보고, 수익률이 더 높은 방향을 스스로 찾아 적용해 주는 옵션입니다. 직접 광고 위치를 하나하나 고민할 필요 없이, 구글에게 최적화를 맡기는 편이 초보자에게는 더 안전합니다.

이 장에서 배운 것

  • 애드센스 코드를 삽입하고 사이트 연결을 완료해 심사를 요청하는 절차를 익혔습니다.
  • 심사 승인 후 ads.txt를 배포해야 광고 게재가 최종 완료된다는 것을 배웠습니다.
  • 자동 광고와 자동 최적화를 켜서 구글이 수익률을 실험하도록 맡기는 법을 익혔습니다.

애드센스는 코드 삽입으로 끝나는 게 아니라, 심사와 ads.txt까지 마쳐야 비로소 광고 게재가 완성됩니다.
