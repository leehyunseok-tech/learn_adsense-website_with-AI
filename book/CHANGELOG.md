# 바뀐 것들

이 책의 변경 이력입니다.
`python tools/build_changelog.py` 가 이 파일을 읽어
`back/changelog.html` 을 만듭니다.

묶음 이름은 **더함 / 고침 / 뺌 / 바꿈** 네 가지만 씁니다.

## [1.1.0] - 2026-08-29
### 더함
- 부록 B "애드핏과 쿠팡 파트너스 병행하기"를 추가했습니다. 애드센스를 메인으로 유지하면서 카카오 애드핏(심사가 급할 때의 보조 카드)과 쿠팡 파트너스(추천 콘텐츠에 녹이는 법·필수 고지 문구)를 다룹니다
- 용어 사전에 "카카오 애드핏", "쿠팡 파트너스" 항목을 추가했습니다
### 뺌
- 표지의 각 쪽마다 붙어 있던 "완성" 상태 배지를 없앴습니다. 책을 다 쓴 뒤에는 전부 "완성"만 반복돼 정보가 없었습니다
